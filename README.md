# لیستیا ۲.۰ — بازنویسی کامل با React + Node.js

نسخه‌ی جدید لیستیا به‌طور کامل با **React 19 + Vite** (فرانت‌اند) و **Node.js + Express** (بک‌اند) بازنویسی شده و رابط کاربری آن از پایه با طراحی مدرن «آرورا گلس» (شیشه‌مات، گرادیان نئونی، تم تیره/روشن) و **انیمیشن برای همه‌ی پنجره‌ها و صفحات** ساخته شده است.

> نسخه‌ی پایتون (Flask) بدون تغییر در همان فایل‌های قبلی نگه داشته شده تا داده و مرجع حفظ شود؛ هر زمان خواستید می‌توانید حذفش کنید.

## اجرا

```bash
npm install        # نصب وابستگی‌ها (ورک‌اسپیس: server + client)
npm run seed       # (اختیاری) ساخت مدیر + کاربر دمو با داده‌ی نمونه
npm run dev        # اجرای توسعه: API روی 3001 و React روی 5173 (با پروکسی /api)
npm run build      # ساخت نسخه‌ی پروداکشن فرانت‌اند (client/dist)
npm start          # اجرای پروداکشن: Express هم API و هم فرانت‌اند را روی یک پورت سرو می‌کند
```

- در پروداکشن فقط `PORT` را ست کنید (پیش‌فرض 3001)؛ فایل‌های `client/dist` به‌صورت خودکار سرو می‌شوند.
- دیتابیس: SQLite داخلی (`node:sqlite` — بدون نیاز به نصب چیز اضافه) در `server/data/listia.db`.
- احراز هویت **دو لایه** است: کوکی‌ی نشست + توکن Bearer (ذخیره در localStorage). توکن برای وقتی است که مرورگر کوکی را بلاک کند (مثل باز شدن اپ داخل iframe با third-party cookies خاموش، یا Safari).

## ساختار

```
server/                 بک‌اند Express
├── index.js            نقطه‌ی ورود (API + سرو فرانت‌اند در پروداکشن)
├── seed.js             داده‌ی نمونه
├── lib/
│   ├── db.js           SQLite + اسکیما (node:sqlite)
│   ├── auth.js         scrypt، نشست کوکی امضاشده، محدودسازی نرخ
│   ├── licensing.js    سامانه‌ی لایسنس (سازگار با نسخه‌ی پایتون)
│   ├── queries.js      منطق دامنه: سهمیه، اشتراک، داشبورد، برآورد
│   ├── importer.js     ایمپورت CSV/XLSX
│   ├── priceSearch.js  جستجوی قیمت زنده (دیجی‌کالا/ترب/باسلام)
│   └── utils.js        اعداد فارسی، تاریخ شمسی، اعتبارسنجی
└── routes/             auth / app / account / admin / token

client/                 فرانت‌اند React 19 + Vite
├── src/pages/          صفحه‌ها (داشبورد، خریدها، تأمین‌کننده‌ها، برآورد، …)
├── src/components/     Modal انیمیشنی، Layout، فرم‌ها، توست، …
├── src/context/        کاربر جاری، سهمیه‌ها، توست/تأیید
└── src/styles/         سیستم طراحی (تم، کامپوننت، چیدمان، صفحات)
```

## امکانات (پورت کامل نسخه‌ی قبلی)

- **احراز هویت**: ثبت‌نام، ورود، تأیید ایمیل با کد ۶ رقمی (SMTP اختیاری — بدون SMTP در حالت توسعه کد نمایش داده می‌شود)
- **تأمین‌کننده‌ها و محصولات**: ثبت/ویرایش/حذف، بررسی تکراری، autocomplete
- **بایگانی**: گروه‌بندی بر اساس تاریخ شمسی، بازگردانی، حذف گروه
- **برآورد قیمت**: قیمت واحد، تعداد در واحد، سقف بودجه با نوار پیشرفت، «خرید بعدی»، برش خودکار تا بودجه، جستجوی قیمت زنده
- **جستجوی سراسری** (Ctrl+K)
- **ایمپورت CSV/XLSX** با گزارش خطای ردیف‌به‌ردیف + فایل نمونه
- **لایسنس**: کلیدهای سازگار با نسخه‌ی قبلی (HMAC یکسان)، سهمیه‌ی نسخه آزمایشی (۱ تأمین‌کننده / ۵ محصول)
- **اشتراک‌گذاری داده** با کاربران دیگر
- **کلید API** برای ثبت از بیرون اپ (`POST /api/quick-add`)
- **پنل مدیریت**: ویرایش کاربران، اعطا/حذف لایسنس، تولید کلید (فردی و Master)
- **UI مدرن**: انیمیشن باز/بسته شدن همه‌ی مودال‌ها (اسپرینگ)، ترنزیشن صفحه‌ها، توست، شمارنده‌های متحرک، تم تیره/روشن، موبایل‌فرندلی

## متغیرهای محیطی

نمونه در `.env.example` — مهم‌ترین‌ها: `PORT`, `SECRET_KEY`, `LICENSE_SECRET` (پیش‌فرض با نسخه‌ی پایتون یکسان است تا کلیدها معتبر بمانند), `ADMIN_USERNAMES`, `ADMIN_PASSWORD`, `SMTP_*`, `COOKIE_INSECURE=1` (برای اجرای محلی روی http).
